# 游戏会话被挤下线后的自动恢复设计

## 1. 背景与目标

游戏可能在挂机期间被其他登录者挤下线，界面会显示“重复登录账号，请重新登录游戏”。如果继续执行原任务，后续点击都可能落在错误界面上。

本功能的目标是：全局识别该弹窗，立即停止当前任务的后续操作，重启游戏抢回控制权，等待回到主城后重试被中断的任务；连续恢复异常时停止挂机并提示人工处理。

约束：10 分钟内最多自动重启 2 次；默认不改变任何任务的业务流程；没有确认弹窗时不得执行强制重启。

## 2. 方案选择

### 方案 A：全局会话保护器（采用）

在 `TaskContext.screenshot()` 统一检查专用重复登录模板。检测到后由 `GameSessionGuard` 执行限频、停止游戏、重新启动和主城等待，然后抛出可识别的会话中断结果。`BotEngine` 收到该结果后重试当前任务。

优点是旧 Python 任务和 Pipeline 自动获得同一套保护；任务内部不需要复制弹窗逻辑。截图是所有现有流程共享的观察点，能覆盖任务中途被挤下线的情况。

### 方案 B：仅在每轮任务开始前检查

实现简单，但任务执行中途出现弹窗时仍可能继续点击，无法满足“随时可能被挤下去”的要求。

### 方案 C：每个任务各自处理

可以针对特殊任务定制恢复，但会复制逻辑，容易遗漏见证传奇、名士拜访等任务，也不利于后续 Pipeline 复用。

## 3. 组件与职责

### GameSessionGuard

- 使用 `duplicate_login_message` 和 `duplicate_login_confirm` 专用模板，在中央弹窗 ROI 内识别。
- 模板文件缺失或未命中时保持静默，不使用固定坐标重启。
- 记录最近 10 分钟的重启时间。
- 未超过上限时执行：`stop_game()` → `start_game()` → 等待游戏前台 → 等待 `nav_fief` 命中。
- 成功恢复后抛出 `GameSessionRestarted`，使当前任务在旧界面上立即停止。
- 超过上限或重启后无法回到主城时抛出不可恢复错误。

### TaskContext

保留现有 `device`、`matcher` 和任务状态接口，增加可选的 `session_guard`。`screenshot()` 先取图，再交给保护器检查；保护器触发恢复时不返回旧截图。

### BaseTask 与 PipelineTask

识别 `GameSessionRestarted` 和恢复失败异常，转成带有结构化标记的 `TaskResult`，而不是把它们当普通业务失败吞掉。这样引擎可以重试当前任务或停止挂机。

### BotEngine

- 每轮开始和每个任务开始仍保留现有通用弹窗清理。
- 任务中发生会话恢复时，最多重新执行当前任务，不跳到下一个任务。
- 恢复达到上限或恢复失败时停止挂机循环，并在状态日志中给出原因。
- 不修改 `mingshi`、`legend`、`guoguan` 的业务实现和每日状态逻辑。

## 4. 数据流

```text
任务调用 ctx.screenshot()
        ↓
GameSessionGuard 检查重复登录弹窗
        ├─ 未命中 → 返回当前截图，任务继续
        └─ 命中 → 限频检查
                    ├─ 超限/重启失败 → NOT_READY，停止挂机
                    └─ 重启游戏并确认主城
                               ↓
                    GameSessionRestarted
                               ↓
                    BotEngine 重试当前任务
```

## 5. 错误处理与安全边界

- 重复登录检测只使用专用模板和中央 ROI，不能使用“确定”按钮的通用模板代替。
- 检测到弹窗后，当前任务不再执行任何点击；恢复流程直接停止应用。
- 重启时间窗口使用单调时钟，避免系统时间变化导致限频失效。
- 默认每 10 分钟最多 2 次重启；超过后不再尝试，避免重启死循环。
- 重启后必须确认游戏在前台且主城模板命中，不能仅凭等待时间认为恢复成功。

## 6. 测试策略

- `GameSessionGuard`：弹窗命中、未命中、模板缺失、重启顺序、主城等待、10 分钟限频。
- `TaskContext`：检测到弹窗后抛出中断，不调用后续任务点击。
- `BaseTask`/`PipelineTask`：恢复中断结果映射正确。
- `BotEngine`：恢复后只重试当前任务，超限后停止循环。
- 8787 冒烟：在用户账号出现该弹窗时确认重启、主城恢复、任务重试和最终恢复原配置。
