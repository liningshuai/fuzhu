# 夜观星象 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在每日最多三次、只消费免费“星晷”道具的前提下，自动完成“夜观星象”，并在成功、跳过或失败后回到主城。

**Architecture:** 新增一个继承 `BaseTask` 的 `StargazeTask`，将流程拆成主城、封地、书院、观星弹窗、奖励弹窗和退出状态。任务只在模板明确命中免费按钮时点击，检测到元宝购买或识别不确定时立即停止；导航、弹窗清理、会话恢复和每日记录复用现有模块。

**Tech Stack:** Python 3、OpenCV 模板匹配、现有 `TaskContext`/`BaseTask`、`unittest`、YAML 配置。

## Global Constraints

- 稳定性优先，使用 Python `BaseTask`，不使用 Pipeline 作为主实现。
- 不增加元宝付费开关，也不点击任何元宝观星按钮。
- 所有轮询、滑动、奖励跳过和返回循环都有明确上限。
- 今日已经完成或没有免费“星晷”时返回 `TaskStatus.SKIPPED`。
- 每次点击后重新截图；免费按钮和付费按钮都未识别时禁止盲点。
- 成功、跳过和失败路径都尽量调用 `ensure_main_city`。
- 项目不是 Git 仓库，不初始化 Git、不创建 worktree、不提交代码。

## State Machine

```text
MAIN_CITY
  -> FIEF_PAGE              点击封地并确认进入
  -> SEARCH_ACADEMY         有界滑动寻找书院
  -> FREE_MARKER_FOUND      只在免费图标命中时进入书院
  -> STARGAZE_DIALOG        识别观星标题/弹窗
  -> FREE_ITEM_AVAILABLE    命中星晷×1，点击一次
  -> REWARD_POPUP           识别奖励层后点击安全空白处
  -> STARGAZE_DIALOG        重新截图，最多三次
  -> PAID_ONLY              命中元宝入口，停止且不点击
  -> RETURN_FIEF             点击 X 回到封地
  -> DONE/SKIPPED/FAILED     点击世界或确保回到主城
```

`SEARCH_ACADEMY` 最多执行 4 次短滑动；一次免费观星完成后最多等待 6 秒识别奖励层，并最多点击 8 次安全空白。整个任务最多处理 3 次免费观星。

## Task 3: Implement the bounded `StargazeTask`

**Files:** Create `src/tasks/stargaze.py`; test with `tests/session/test_stargaze.py`.

**Interfaces:**

- `StargazeTask.execute(ctx) -> TaskResult`.
- `_completed_today() -> bool` reads `last_completed_date` and `completed_today`.
- `_save_completed() -> None` writes both fields through `config.set_task_option` and `config.save_runtime`.
- `open_fief(ctx) -> bool`, `find_and_open_academy(ctx) -> bool`, `is_stargaze_dialog(ctx, screen=None) -> bool`, `observe_once(ctx) -> str`, `_leave_to_main(ctx) -> bool`.

- [ ] **Step 1: Implement date guard and required-template guard**

  The class must declare all required templates. A completed date returns `SKIPPED` before any screenshot tap. Missing templates return `NOT_READY` through `BaseTask`.

- [ ] **Step 2: Implement bounded navigation**

  Use `ensure_main_city`, a template-first click for `nav_fief`/`nav_world`, and fixed coordinate fallbacks only at the known 1080×1920 locations. Search the academy with at most four `device.swipe(...)` calls and take a fresh screenshot after each one.

- [ ] **Step 3: Implement free-versus-paid decision**

  In the dialog, search `stargaze_free_item` before any click. If `stargaze_paid_observe` matches, return `"paid"` without tapping. If neither matches, return `"unknown"` without tapping. Only `"free"` can tap the free button.

- [ ] **Step 4: Implement reward and exit handling**

  After a free click, recognize a reward popup using the existing safe popup detector or a dedicated template if available; only then tap `(30, 500)`, with a maximum of eight taps. Close the dialog through `stargaze_close` or its fixed X fallback, then tap `nav_world` and verify `is_main_city`.

- [ ] **Step 5: Implement the three-observation loop**

  Repeat at most `max_free_observations` (default 3). A paid or unknown state stops safely. Save completion only after at least one successful free observation and a confirmed return to main city. Return `SKIPPED` for no free marker/paid-only, `FAILED` for navigation or recovery failure, and `SUCCESS` after successful completion.
